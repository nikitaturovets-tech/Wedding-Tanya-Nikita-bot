# 💒 Свадебная фотостена — Таня & Никита

Система для сбора и отображения фото от гостей на большом экране в реальном времени.

---

## Как это работает

1. Гость открывает бота в Telegram и присылает фото
2. Бот сохраняет фото на сервер
3. Стена на большом экране автоматически обновляется каждые 3 секунды
4. Все видят фото друг друга на экране в зале

---

## Быстрый старт (пошагово)

### Шаг 1 — Создай бота в Telegram

1. Открой Telegram и найди бота **@BotFather**
2. Отправь ему команду `/newbot`
3. Придумай **имя бота** (например: `Свадьба Тани и Никиты`)
4. Придумай **username бота** — должен заканчиваться на `bot` (например: `tanya_nikita_wedding_bot`)
5. BotFather пришлёт тебе **токен** — длинную строку вида `1234567890:ABCdef...`
   Сохрани его, он понадобится на следующем шаге.

### Шаг 2 — Узнай свой Telegram ID (для администратора)

1. Найди в Telegram бота **@userinfobot**
2. Нажми `/start`
3. Он пришлёт твой **ID** — число вида `123456789`
   Сохрани его.

### Шаг 3 — Залогинься на VPS и клонируй проект

```bash
# Подключись к серверу по SSH
ssh root@ВАШ_IP_СЕРВЕРА

# Клонируй репозиторий
git clone ВСТАВЬ_СЮДА_ССЫЛКУ_НА_РЕПОЗИТОРИЙ wedding-wall

# Перейди в папку проекта
cd wedding-wall
```

### Шаг 4 — Создай файл .env с настройками

```bash
# Скопируй шаблон
cp .env.example .env

# Открой файл для редактирования
nano .env
```

Заполни файл своими данными:

```
BOT_TOKEN=1234567890:ABCdef...   ← токен от BotFather
ADMIN_ID=123456789               ← твой Telegram ID от @userinfobot
```

Сохрани файл: `Ctrl+O`, затем `Enter`, затем `Ctrl+X`.

### Шаг 5 — Запусти деплой одной командой

```bash
bash deploy.sh
```

Скрипт сам:
- обновит код
- установит зависимости
- откроет порт 8080
- запустит бота и сервер в фоне

В конце увидишь адрес стены, например: `http://185.123.45.67:8080`

### Шаг 6 — Открой стену на большом экране

1. Открой браузер на компьютере, подключённом к экрану
2. Введи адрес из предыдущего шага: `http://ВАШ_IP:8080`
3. Нажми **F11** для полноэкранного режима

### Шаг 7 — Поделись ботом с гостями

Дай гостям ссылку на бота:
```
https://t.me/ИМЯ_ВАШЕГО_БОТА
```
(например: `https://t.me/tanya_nikita_wedding_bot`)

Можно распечатать QR-код к этой ссылке на столиках.
Сгенерировать QR: зайди на сайт [qr.io](https://qr.io) и вставь ссылку.

## Управление сессиями

**Сессия** — это набор фотографий, привязанных к конкретному запуску стены.
Стена всегда показывает только фото текущей активной сессии.

Это позволяет:
- Скрыть тестовые фото перед началом торжества
- Начать «чистую» стену в любой момент
- Использовать систему на нескольких мероприятиях

### Команды администратора

Эти команды доступны только тебе (ADMIN_ID из .env):

| Команда | Что делает |
|---|---|
| `/newsession` | Начинает новую сессию. Старые фото скрыты со стены, но остаются на диске |
| `/clearsession` | Удаляет все фото текущей сессии с диска |
| `/status` | Показывает количество фото, время начала сессии |

## Часто задаваемые вопросы (FAQ)

**Стена не открывается в браузере**
- Проверь, что сервер запущен: `screen -ls` должен показать `wedding-server`
- Проверь, что порт открыт: `sudo ufw status | grep 8080`
- Попробуй открыть с самого сервера: `curl http://localhost:8080`

**Бот не отвечает**
- Проверь, что бот запущен: `screen -ls` должен показать `wedding-bot`
- Проверь токен в `.env` файле — он должен совпадать с токеном от BotFather
- Посмотри логи: `cat logs/bot.log`

**Фото не появляются на стене**
- Убедись, что папка `photos/` существует: `ls photos/`
- Проверь, что в `photos_meta.json` есть записи: `cat photos_meta.json`
- Убедись, что `session_id` в метаданных совпадает с `session.json`

**Хочу начать заново (сбросить все фото)**
- Напиши боту `/newsession` — стена очистится, файлы останутся
- Или `/clearsession` — файлы будут удалены

**Как обновить код после изменений**
```bash
cd wedding-wall
bash deploy.sh
```

**На экране не 12 фото — меньше**
- Это нормально: стена показывает последние 12 фото. Как только гости пришлют больше, старые будут вытесняться.

## Структура файлов

```
wedding-wall/
├── bot.py              ← Телеграм-бот
├── server.py           ← HTTP-сервер
├── wall.html           ← Веб-стена
├── requirements.txt    ← Зависимости Python
├── .env                ← Секреты (не в git!)
├── .env.example        ← Шаблон .env
├── deploy.sh           ← Скрипт деплоя
├── photos/             ← Папка с фото (не в git!)
├── photos_meta.json    ← Метаданные фото (не в git!)
├── session.json        ← Текущая сессия (не в git!)
└── logs/               ← Логи бота и сервера
```
