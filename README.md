# 💒 Свадебная фотостена + Квиз — Таня & Никита

Система для свадьбы на 45+ гостей:
- **Телеграм-бот** принимает фото от гостей и проводит интерактивный квиз
- **Веб-стена** показывает фото в реальном времени и лидерборд квиза на большом экране

---

## Как это работает

| Гость | Экран в зале |
|---|---|
| Открывает бота, присылает фото | Фото появляется на стене через 3 сек |
| Нажимает кнопку ответа в квизе | Лидерборд обновляется в реальном времени |

---

## Быстрый старт (пошагово)

### Шаг 1 — Создай бота в Telegram

1. Открой **@BotFather** → `/newbot`
2. Придумай имя (например: `Свадьба Тани и Никиты`) и username (например: `tanya_nikita_wed_bot`)
3. BotFather пришлёт **токен** — строка вида `1234567890:ABCdef...` — сохрани его

### Шаг 2 — Узнай свой Telegram ID

1. Открой **@userinfobot** → `/start`
2. Он пришлёт твой **ID** — число вида `123456789` — сохрани его

### Шаг 3 — Клонируй проект на VPS

```bash
ssh root@ВАШ_IP_СЕРВЕРА
git clone ССЫЛКА_НА_РЕПОЗИТОРИЙ wedding-wall
cd wedding-wall
```

### Шаг 4 — Создай файл .env

```bash
cp .env.example .env
nano .env
```

Заполни:
```
BOT_TOKEN=1234567890:ABCdef...    ← токен от BotFather
ADMIN_ID=123456789                ← твой Telegram ID
```
Сохрани: `Ctrl+O` → `Enter` → `Ctrl+X`

### Шаг 5 — Отредактируй вопросы квиза

```bash
nano quiz.json
```

Структура каждого вопроса:
```json
{
  "question": "Где познакомились жених и невеста?",
  "options": ["В университете", "На вечеринке", "В приложении", "На работе"],
  "correct": 1
}
```
`correct` — индекс правильного ответа (0, 1, 2 или 3).

### Шаг 6 — Задеплой одной командой

```bash
bash deploy.sh
```

Скрипт установит зависимости, откроет порт 8080, запустит бота и сервер.
В конце выведет адрес стены: `http://185.123.45.67:8080`

### Шаг 7 — Открой стену на экране в зале

1. Открой браузер → введи `http://ВАШ_IP:8080`
2. Нажми **F11** — полноэкранный режим
3. Подключи ноутбук к проектору / телевизору

## Сценарий квиза на свадьбе

```
1. Объяви гостям: "Достаньте телефоны и откройте бота!"
   Дай им 2–3 минуты написать /start и убедиться что бот работает.

2. Напиши боту /startquiz
   → Бот разошлёт вопрос 1 всем гостям
   → На экране появится режим квиза с вопросом и лидербордом

3. Подожди 30–60 секунд (на экране видно сколько ответили)

4. Напиши /nextquestion
   → Бот разошлёт правильный ответ + вопрос 2
   → Лидерборд обновится

5. Повторяй шаги 3–4 для каждого вопроса

6. После последнего вопроса напиши /results
   → Финальный лидерборд на весь экран
   → Каждый гость получит личный результат в личку
   → Через 30 секунд стена автоматически вернётся к фото
```

## Команды администратора (только для тебя)

### Квиз

| Команда | Действие |
|---|---|
| `/startquiz` | Начать квиз, разослать вопрос 1 всем гостям |
| `/nextquestion` | Показать ответ на текущий вопрос + задать следующий |
| `/results` | Завершить квиз, разослать итоги, показать лидерборд на экране |
| `/stopquiz` | Остановить квиз без итогов, вернуть стену к фото |

### Фото и сессии

| Команда | Действие |
|---|---|
| `/newsession` | Начать новую сессию — старые фото скрыты со стены, но остаются на диске |
| `/clearsession` | Физически удалить фото текущей сессии с диска |
| `/status` | Показать кол-во фото, время начала, session_id, кол-во гостей в боте |

### Тосты

| Команда | Действие |
|---|---|
| `/queue` | Список очереди тостов |
| `/nexttoast` | Убрать первого из очереди, уведомить следующего |
| `/clearqueue` | Очистить очередь полностью |

## Изменить имена на стене

Открой `wall.html`, найди строку:
```html
<h1>💒 Таня &amp; Никита</h1>
```
Замени имена. Обновление страницы в браузере применит изменение без перезапуска сервера.

## FAQ

**Стена не открывается**
- `screen -ls` → должен быть `wedding-server`
- `sudo ufw status | grep 8080` → порт должен быть открыт
- `curl http://localhost:8080` → проверь ответ

**Бот не отвечает**
- `screen -ls` → должен быть `wedding-bot`
- Проверь токен в `.env` — он должен совпадать с BotFather
- `tail -50 logs/bot.log` → посмотри последние строки

**Квиз не запускается**
- Убедись что `quiz.json` существует и заполнен: `cat quiz.json`
- Бот сообщит об ошибке если файл не найден или пустой

**Гости не получают вопросы**
- Гость должен написать боту хотя бы раз (`/start` или любое сообщение)
  до запуска `/startquiz` — только тогда он получает рассылку
- Проверь логи: `tail -30 logs/bot.log`

**Фото не появляются на стене**
- `ls photos/` → фото должны быть в папке
- `cat photos_meta.json` → записи должны совпадать по `session_id` с `cat session.json`

**Хочу сбросить всё и начать заново**
- `/newsession` — стена чистая, файлы на диске остаются
- `/clearsession` — файлы тоже удаляются

**Как обновить код**
```bash
bash deploy.sh
```
